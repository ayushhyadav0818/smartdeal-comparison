# 🚀 SmartDeal - Real-Time Price Comparison Engine

SmartDeal is a modern, high-fidelity, and animated web application designed to aggregate and compare product pricing, delivery times, return policies, and active coupons across top e-commerce platforms (Amazon, Flipkart, Myntra, Ajio, and official brand stores) in real-time.

Designed with a cyber-metallic dark theme, fluid CSS micro-animations, and live data synchronization indicators.

---

## ✨ Features
* 🔍 **Real-Time Autocomplete Search**: Interactive search input with instant matching.
* 🏷️ **Category Filter Badges**: Quickly filter results by Electronics, Footwear, or Fashion.
* 💚 **Smart Best-Deal Highlight**: Automatically highlights the cheapest deal with a pulsing emerald glow.
* 🎟️ **Active Coupon Code Drawer**: Displays and calculates extra discounts at checkout.
* 📈 **30-Day Historical Price Chart**: Visualizes pricing trends utilizing Chart.js.
* 🎯 **Value Assessment & Verdicts**: Radial progress indicators detailing target value scores.
* 🔔 **Price Drop Alerts Webhook**: Set target prices and emails for automated notifications.

---

## 🛠️ Tech Stack
* **Structure**: Semantic HTML5
* **Styling**: Vanilla CSS3 (Custom Variables, Backdrop-filters, Keyframe Animations)
* **Logic**: Vanilla ES6 JavaScript
* **Visualizations**: Chart.js (via CDN)
* **Icons**: Lucide Icons (via CDN)

---

## 🚀 Running Locally
Simply spin up any static file server in this directory.

**Using Python:**
```bash
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

---

## ☁️ Deployment to Vercel
Since it is a fully static project, deploy it directly:
```bash
npm install -g vercel
vercel
```
Or import this repository directly into the Vercel Dashboard!
